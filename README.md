# 社労士 横断マスター 🔀🧠

社会保険労務士試験のための学習 PWA(Progressive Web App)。
**横断学習** を軸に、**アクティブリコール** で覚え、**忘却曲線** で復習タイミングを最適化します。

ビルド不要・依存パッケージなしの素の静的サイトです。リポジトリのルートがそのまま公開対象です。

> ⚠️ 同梱の問題データは動作確認用のサンプルです。法令は毎年改正されるため、
> 実際の受験対策では最新の条文・通達で必ず裏取りしてください。

## 3つの柱

| 機能 | 中身 |
|---|---|
| 🔀 **横断学習** | 「時効」「不服申立て」「年齢要件」など、科目をまたぐ同一論点を比較表で整理 |
| 🧠 **アクティブリコール** | 問題を見て自分で思い出す → 答えを表示 → 4段階で自己採点(忘れた/あいまい/覚えた/余裕) |
| 📈 **成長と忘却の可視化** | 記憶の予測カーブ、学習量の推移、科目別の習得度バー |

ほかに **ダークモード**(ヘッダーの 🌙/☀️)、**復習リマインド**(成長画面でON)、
**間違えた問題だけ復習(苦手復習)**、**CSV/JSON 一括インポート** に対応しています。

## 仕組み(忘却曲線)

各カードは **安定度 stability(日)** を持ちます。これは「保持率が 90% まで下がるまでの日数」です。

```
保持率 R(t) = 0.9 ^ (t / stability)     t = 前回復習からの経過日数
```

- 復習で「覚えた/余裕」を選ぶほど stability が伸び、忘れにくくなります。
- 「忘れた」を選ぶと stability が縮み、すぐに再出題されます。
- 次の復習期限は `t = stability`(= 保持率が 90% に下がる日)に設定されます。

実装は `js/srs.js`(SM-2 を簡略化したアルゴリズム)にあります。

## 使い方(ローカル)

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

スマホでは「ホーム画面に追加」でアプリのように使えます(オフライン対応)。

## GitHub Pages で公開する(自動デプロイ)

`.github/workflows/pages.yml` を同梱しています。`main` を更新すると自動で公開されます。

1. リポジトリの **Settings → Pages → Build and deployment** を開く
2. Source を **「GitHub Actions」** に設定(初回のみ)
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます

## 問題を追加する(2通り)

### A. 画面からインポート(コード不要)

「成長」→「問題をインポート」から、CSV / JSON を貼り付け・ファイル選択で一括取り込みできます(形式は自動判定)。

CSV の例(1行目はヘッダー。`question`/`answer` は必須、`topic` が同じ行は1テーマにまとまる):

```csv
topic,subjects,question,answer,hint,source
労働時間,労基|安衛,法定労働時間は1日何時間?,8時間,原則,R5択一
労働時間,労基,法定労働時間は1週何時間?,40時間,,
```

### B. `js/content.js` を編集(比較表も作りたい場合)

1テーマ = 比較表(`table`)+ 一問一答(`cards`)。

```js
{
  id: 'my-topic',
  title: 'テーマ名',
  tagline: '一言説明',
  subjects: ['kijun', 'rosai'],     // SUBJECTS のキー
  note: '補足メモ',
  table: {
    headers: ['列1', '列2'],
    rows: [ ['A', 'B'], ['C', 'D'] ],
  },
  cards: [
    { q: '問題文', a: '答え', hint: '任意のヒント', source: '任意の出典(例: R5択一・労基)' },
  ],
}
```

## ファイル構成

```
.
├── index.html              画面の骨格
├── styles.css              スタイル(モバイルファースト)
├── manifest.webmanifest    PWA 設定
├── sw.js                   Service Worker(オフライン対応)
├── icons/icon.svg          アプリアイコン
├── .github/workflows/
│   └── pages.yml           GitHub Pages 自動デプロイ
└── js/
    ├── content.js          学習コンテンツ(ここを増やす)
    ├── srs.js              間隔反復・忘却曲線の計算
    ├── storage.js          進捗の保存(localStorage)
    ├── charts.js           Canvas でのグラフ描画
    ├── import.js           CSV/JSON インポート
    └── app.js              画面遷移とロジック
```

## データの保存場所

学習進捗は端末のブラウザ(localStorage)に保存されます。サーバーには何も送信しません。
「成長」画面からバックアップ(JSON)の書き出しができます。
