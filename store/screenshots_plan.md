# スクリーンショット計画 — 社労士試験横断アプリ

最終更新: 2026-06-18 / 作成: sharo-store チーム
※ 寸法は2026年6月時点のApple/Google公式仕様で照合（出所は末尾）。提出直前に再確認推奨。

## 1. 必要枚数・寸法まとめ

### App Store（iOS）
| デバイスクラス | 推奨解像度(縦) | 代替で可 | 必須 | 枚数 |
|---|---|---|---|---|
| iPhone 6.9"（基準） | **1320 × 2868 px** | 6.7" の 1290×2796 も可 | **必須**（最低1枚） | 2〜3枚推奨（最大10枚） |
| iPad 13"（基準） | **2064 × 2752 px** | 12.9" の 2048×2732 も可 | **iPad対応する場合のみ必須** | iPad対応時 1枚以上 |

- 形式: **PNG 推奨**（テキスト鮮明）。JPEGも可。
- Appleは大きい基準サイズをアップすれば小型デバイス向けに自動縮小する → **6.9"を1セット作れば下位iPhoneは自動対応**。
- **iPad非対応で申請すれば、iPad用スクショは不要**（手間を減らす選択肢）。本アプリはportrait固定なので、まずは「iPhoneのみ」で出すのが楽。

### Google Play（Android）
| 資産 | 寸法 | 必須 | 枚数 |
|---|---|---|---|
| スマホ用スクショ | **1080 × 1920 px 推奨**（短辺320px以上・長辺3840px以下・アスペクト比9:16〜16:9） | **必須** | **最低2枚**（推奨4枚以上・最大8枚） |
| フィーチャーグラフィック | **1024 × 500 px（厳密・例外なし）** | **必須** | 1枚 |
| アプリアイコン | 512 × 512 px（32bit PNG） | 必須 | 1枚（既存icon-512から作成可） |

- 形式: JPEG または 24bit PNG（アルファなし）。1枚最大8MB。

## 2. 撮影する画面（指定）

本アプリの3画面（ホーム / 問題 / 使い方）と横断表を素材に、以下5カットを用意。最初の2枚が最重要（一覧で最初に見える）。

1. **【ホーム】テーマ一覧**
   - 「横断テーマ」一覧が並ぶ画面。科目チップ（横断/労基/労災…）が見えるように。
   - キャプション案: 「200以上のテーマを横断・科目別に」
2. **【横断表】比較表を開いた状態**
   - 似た制度を同じ軸で並べた比較表。差分が一目でわかる画面。
   - キャプション案: 「紛らわしい制度を“同じ軸”で比較」
3. **【問題】○×一問一答（出題中）**
   - 問題文が表示され、まだ答えを見ていない状態。
   - キャプション案: 「まず思い出す。アクティブリコール学習」
4. **【問題】答え合わせ（解説表示）**
   - ○×の正誤＋解説・ポイントが見えている状態。
   - キャプション案: 「解説とポイントで理解を定着」
5. **【使い方/情報】**
   - 使い方・プライバシー（端末内完結・登録不要・無料）が見える画面。
   - キャプション案: 「登録不要・無料・端末内で完結」

> キャプション（文字焼き込み）は任意。入れる場合もメモリ方針に従い、下町トーン・余計な装飾は避けクリーンに。文字なしの素のスクショでも提出は可能。

## 3. ローカルでスクショを生成する方法（実機不要・推奨）

GitHub Pages公開済みURL（https://makotoikeda1977.github.io/sharo-master/ ）を使い、**Chromeのデバイスモードで正確なピクセル寸法のスクショを撮る**のが最も手軽。Macだけで完結し、実機もXcodeも不要。

### 方法A: Chrome DevTools デバイスモード（最も簡単）
1. Chromeで公開URLを開く
2. `Cmd+Option+I` でDevTools → デバイスツールバー（`Cmd+Shift+M`）をON
3. 上部の解像度入力に **数値を直接指定**（DPR=1 で実ピクセル一致させる）
   - iPhone 6.9": `1320 × 2868`（※「Responsive」で幅1320/高さ2868、DPR=1）
   - iPhone 6.7": `1290 × 2796`
   - Android: `1080 × 1920`
   - iPad 13": `2064 × 2752`
4. DevTools右上「⋮」→ **Capture screenshot**（または Capture full size screenshot）でPNG保存
   - ※ DPRを2にすると論理サイズの2倍で出るため、**寸法を実ピクセルに合わせるならDPR=1で幅・高さをそのまま実pxに指定**するのが確実。出力後に寸法を確認すること。

### 方法B: ヘッドレスChromeでコマンド一発（自動化したい場合）
```bash
# 例: iPhone 6.9" 相当（1320x2868）。--hide-scrollbars でスクロールバー除去
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" \
  --headless --disable-gpu --hide-scrollbars \
  --window-size=1320,2868 \
  --screenshot="$HOME/Downloads/sharo_shots/ios_69_home.png" \
  "https://makotoikeda1977.github.io/sharo-master/"
```
- 画面ごとにURLハッシュ/操作が要る場合は、各ルート（home/review/info）を開いた状態で撮る。SPAなので、撮りたい画面に遷移してから方法Aの方が確実。
- 撮影後に寸法が規定どおりか確認:
```bash
sips -g pixelWidth -g pixelHeight ~/Downloads/sharo_shots/ios_69_home.png
```

### 方法C: 実機（最も自然な見た目）
- iPhone実機でPWAをホーム画面に追加 → 全画面表示でスクショ → 寸法が機種解像度に一致。
- ただし機種ごとの寸法調整が要るため、提出用は方法A/Bで規定寸法に揃えるのが楽。

## 4. フィーチャーグラフィック（Google Play専用・1024×500）

- アプリ名「社労士試験横断アプリ」＋短いキャッチ（例:「横断×一問一答で記憶に定着」）を配置したバナー。
- 端末枠やスクショの埋め込みは任意。背景はクリーンに（メモリ方針: 下町トーン・招き猫・桜等は入れない／文字数値の過剰な焼き込みも避ける）。
- 作成は新アイコン確定後が望ましい（トーン統一のため）。HTML→Chromeヘッドレスで1024×500を書き出す方法でも生成可能。
